## 已知限制与暂缓事项

| 项目 | 当前状态 |
| --- | --- |
| 注册登录、账号数据库、云端资产同步 | 用户明确暂缓，当前为浏览器本地版 |
| 一键策划 / 迁移分析的站内持续运行 | 尚未纳入常驻页面范围；不要套用工作台分析的保证 |
| 刷新、关闭浏览器后的持续任务 | 没有独立服务端后台任务保障，需人工核查未确认结果 |
| 服务商并发、限流及返回效果 | 由服务商决定；本站按单图并行发出，不保证上游同时处理 |
| 跨域名 / 设备恢复资料与图片 | 当前不支持自动同步，使用图片备份等现有手段 |
| 历史验证脚本 | 部分覆盖旧流程，运行前核对，不一键盲跑 |
| 私人测试输入与本机验证输出 | 不放入通用交接包，不记录密钥 |
